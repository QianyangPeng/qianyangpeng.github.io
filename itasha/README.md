# Model Y Juniper 车衣

适用于 2026 Model Y Juniper Premium 的 Toybox 数字车衣浏览与下载页，包含 78 款按主题整理的 PNG 车衣。

- 按主题筛选，搜索角色、城市或设计名；支持收藏与分享单款链接。
- 拖动旋转、滚轮缩放静态 3D 车模，可切换光线。
- 查看官方模板 PNG 展开图，并逐张下载或按主题批量下载。
- 网站缩略图展示车衣图稿；车机下载文件是 `1024 × 1024` PNG，每张小于 1 MB。

主题数量：小猪佩奇 3 款、原神 20 款、VOCALOID 20 款、西雅图 5 款、武汉 5 款、中国 5 款、东方 Project 20 款。

Tesla App 导入：Creations → Wrap → Upload。U 盘导入：将 ZIP 中的 `Wraps` 文件夹放入 U 盘根目录，在 Toybox → Paint Shop → Wraps 选择。每个批次最多 10 张。

3D 为社区 Juniper 车模上的静态位置预览，车机裁切与接缝可能不同。PNG 文件按 Tesla Premium 模板导出；请先查看展开图，并以车机预览为准。实体贴膜需另行制作施工文件。
